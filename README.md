# 七旬 — 아빠 칠순잔치 게임쇼

빔프로젝터로 띄우는 가족 게임쇼. 퀴즈 2개와 7초 맞추기로 코인을 모으고, 게임 사이에 추억극장 사진을 보고,
마지막에 코인 수만큼 이름 구슬을 넣은 마블 룰렛으로 상품 8개를 나눠 가져요.

## 실행

- **인터넷 없이:** 폴더째 노트북에 두고 `index.html` 을 크롬으로 열기 → `F` 키로 전체화면
- **온라인:** https://seoyoungtaek.github.io/Father_70/

진행 기록(코인·팀 이름·결과)은 그 브라우저에 저장돼요. 새로고침해도 이어서 진행돼요.

## 진행 순서

오프닝(팀 이름) → 추억극장① → 📸 아빠 인생 퀴즈 → 추억극장② → 🔍 확대 사진 퀴즈 → 추억극장③ → ⏱ 7초 맞추기 → 🎰 마블 룰렛 → 엔딩
(사진이 없는 추억극장은 자동으로 건너뜀)

## 키 조작

| 키 | 동작 |
|---|---|
| → / PageDown | 다음 (프레젠터 리모컨도 OK) |
| ← / PageUp | 이전 |
| S | 코인 현황판 (사람별 ± 수동 조정) |
| G | 설정 — 이름·팀·상품 수정, 초기화, 바로 가기 |
| F | 전체화면 |
| Space | 7초 게임 시작/멈춤, 룰렛 출발 |
| R | 7초 다시 하기 / 룰렛 그 판부터 다시 |
| Esc | 창 닫기 |

한글 입력 상태여도 동작해요.

## 규칙

- 퀴즈: 팀이 맞히면 팀원 전원 🪙+1, ⭐ 아이가 외쳐서 맞히면 🪙+2. 확대 퀴즈는 단계별 3·3·2·2·1 (아이 2배).
- 할아버지·할머니는 인생 퀴즈 정답을 직접 외칠 수 없고 손주에게 귓속말만.
- 7초: 1·2·3등 🪙3·2·1, ±0.05초 이내 잭팟 🪙7.
- 룰렛: 코인 1개 = 구슬 1개. 구슬 하나라도 골인하면 통과, 꼴찌가 그 판 상품을 받고 퇴장. 마지막 2명은 1등 결승.

## 내용 고치기

- **퀴즈:** `data/quiz.js` — ✏️ 표시를 실제 내용으로. `answer` 는 정답 보기 번호(첫 번째가 0), `null` 이면 현장 판정.
- **확대 퀴즈:** `data/zoom.js` — `cx, cy` 는 확대 중심(0~1).
- **이름·상품·추억극장 제목:** `data/config.js` (현장에선 G 설정 화면에서도 가능)
- **사진 추가:** `photos/<폴더>/` 에 원본을 넣고 `python tools/build_photos.py` 실행 → `assets/photos/` 에 줄인 사진 생성.
  `photos/베스트컷_목록.txt` 에 `폴더: 이름` 아래 파일을 적으면 그 사진만 그 순서로 슬라이드에 나와요.
  원본 `photos/` 는 Git 에 올라가지 않아요.

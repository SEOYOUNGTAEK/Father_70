# 七旬 — 할아버지 칠순잔치 게임쇼

빔프로젝터로 띄우는 가족 게임쇼. 퀴즈 2개와 7초 맞추기로 코인을 모으고, 게임 사이에 추억극장 사진을 보고,
마지막에 코인 수만큼 이름 구슬을 넣은 마블 룰렛으로 상품 8개를 나눠 가져요.

## 실행

- **인터넷 없이:** 폴더째 노트북에 두고 `index.html` 을 크롬으로 열기 → `F` 키로 전체화면
- **온라인:** https://seoyoungtaek.github.io/Father_70/

진행 기록(코인·팀 이름·결과)은 그 브라우저에 저장돼요. 새로고침해도 이어서 진행돼요.

## 진행 순서

오프닝(팀 이름) → 오늘의 순서 안내 → 추억극장① → 📸 할아버지 인생 퀴즈 → 추억극장② → 🔍 확대 사진 퀴즈 → 추억극장③ → ⏱ 7초 맞추기 → 🎰 마블 룰렛 → 엔딩
(사진이 없는 추억극장은 자동으로 건너뜀)

## 조작 (폰 터치가 기본)

- 화면마다 오른쪽 아래 **큰 버튼**(게임 시작 ▶, 정답 공개 ▶, 🔍 더 보기, 다음 사람 ▶ …)으로 진행해요.
- 양쪽 **◀ ▶**, 좌우로 밀기, 추억극장은 사진 오른쪽 탭=다음 · 왼쪽 탭=이전.
- 오른쪽 위 🪙 코인판 · ⚙ 설정 · ⛶ 전체화면 — 창은 ✕ 닫기나 바깥 터치로 닫아요.

### 키보드로 할 때

| 키 | 동작 |
|---|---|
| → / PageDown | 다음 (프레젠터 리모컨도 OK) |
| ← / PageUp | 이전 |
| S | 코인 현황판 (사람별 ± 수동 조정) |
| G | 설정 — 이름·팀·상품 수정, 초기화, 바로 가기 |
| F | 전체화면 |
| Space | 7초 게임 시작/멈춤, 룰렛 출발 (폰에서는 화면 터치) |
| R | 7초 다시 하기 / 룰렛 그 판부터 다시 |
| Esc | 창 닫기 |

한글 입력 상태여도 동작해요.

**폰 미러링으로 진행할 때:** 크롬에서 사이트를 열고 메뉴 → **홈 화면에 추가** → 홈 화면 아이콘으로 열면 주소창 없이 가로 전체 화면이에요. 오프닝에서 이름을 탭하면 다른 팀으로 옮겨져요.

**폰·태블릿:** 화면 양쪽 ◀ ▶ 버튼이나 좌우로 밀어서 넘겨요. 오른쪽 위 🪙 코인판 · ⚙ 설정 · ⛶ 전체화면. 룰렛은 화면을 탭하면 출발/다음. 버튼은 3초 동안 안 건드리면 투명해지지만 그대로 눌려요.

## 규칙

- 인생 퀴즈: 팀마다 화면에서 ①~④를 클릭해 고르고, → 로 정답을 공개하면 자동 채점(맞히면 팀 전원 🪙+1, ⭐ 아이가 골랐어요를 켜면 🪙+2). 판정 문제는 공개 화면에서 정답 보기를 클릭. 할아버지·할머니는 공개 전까지 쉿!
- 확대 퀴즈: 가족 얼굴 개그 문제 6개, 7단계(최대 40배 확대)로 4번쯤 줄여야 보여요. 먼저 외친 팀에 진행자가 버튼으로 지급, 1~3단계 3 · 4~5단계 2 · 6~7단계 1 (아이 2배).
- 7초: 올라가는 초시계를 보며 본인이 화면을 터치해서 시작·멈춤(손가락이 닿는 순간 기록). 1·2·3등 🪙3·2·1, ±0.05초 이내 잭팟 🪙7.
- 룰렛: 코인 1개 = 구슬 1개. 1등 상품부터 한 판씩, 제일 먼저 골인한 구슬의 주인이 당첨 → 당첨자는 빠지고 다음 상품. 한 판 20초 안팎, 마지막 '역전 구간'(풍차·범퍼)은 슬로모션.

## 내용 고치기

- **퀴즈:** `data/quiz.js` — ✏️ 표시를 실제 내용으로. `answer` 는 정답 보기 번호(첫 번째가 0), `null` 이면 현장 판정.
- **확대 퀴즈:** `data/zoom.js` — `cx, cy` 는 확대 중심(0~1).
- **이름·상품·추억극장 제목:** `data/config.js` (현장에선 G 설정 화면에서도 가능)
- **추억극장:** 모든 사진 폴더의 사진이 촬영 날짜순으로 섞여서 ① 2009–2016 ② 2017–2025 ③ 2026 챕터에 들어가요(`data/config.js` 의 `memories` 기간). 날짜 없는 사진은 `베스트컷_목록.txt` 에서 바로 앞 사진의 날짜를 따라가요.
- **사진 추가:** `photos/<폴더>/` 에 원본을 넣고 `python tools/build_photos.py` 실행 → `assets/photos/` 에 줄인 사진 생성.
  `photos/베스트컷_목록.txt` 에 `폴더: 이름` 아래 파일을 적으면 그 사진만 그 순서로 슬라이드에 나와요.
  원본 `photos/` 는 Git 에 올라가지 않아요.

## 상장 인쇄

`data/certificates.js` 문구를 고친 뒤 `python tools/make_certificates.py` → `print/` 폴더에 A4 세로 300dpi PNG 2장과 PDF 가 생겨요(날짜는 손으로 쓰는 칸). 화면 엔딩도 같은 문구를 써요.

## 새 버전 올릴 때

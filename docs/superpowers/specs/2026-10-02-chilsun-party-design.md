# 아빠 칠순잔치 게임쇼 — 설계

- 작성일: 2026-10-02
- 행사: 약 1개월 후, 펜션, 빔프로젝터 + 노트북 1대
- 진행자: 본인(아들) — 게임에는 참가하지 않음

## 목적

칠순을 맞은 아버지(할아버지)를 주인공으로, 가족 8명이 게임으로 코인을 모으고
그 코인만큼 마블 룰렛에 이름 구슬을 넣어 상품을 추첨한다. 게임 사이에 가족 여행 사진
"추억극장"을 넣어 추억을 소환한다.

## 참가자와 팀 (4인조 2팀)

| 팀 | 아이 | 어른 |
|---|---|---|
| 🅰 | 아들(초2), 조카(초1) | 할아버지, 누나 |
| 🅱 | 조카(초3) | 할머니, 매형, 아내 |

- 팀 이름은 현장에서 아이들이 짓고, 진행자가 화면에서 입력한다.
- 이름·팀 배정은 설정 화면에서 수정 가능 (기본값은 위 표).

## 코인 규칙

- 코인은 **개인별**로 쌓인다. 팀이 맞히면 팀원 4명 모두에게 지급.
- 퀴즈: 팀 정답 → 팀원 전원 +N, **아이가 직접 외친 정답 → 팀원 전원 +2N** (N = 문제 배점).
- 7초 맞추기: 개인전. 1등 3, 2등 2, 3등 1. |오차| ≤ 0.05초면 잭팟 +7(순위 코인 대신).
- 진행자는 언제든 개인 코인을 ±1 수동 조정 가능 (실수 복구용).

## 진행 흐름

```
설정(사전) → 오프닝(칠순 축하 + 팀 이름 입력)
→ 추억극장① 2019 집들이, 2021 중국  → 게임1 아빠 인생 퀴즈
→ 추억극장② 2025 치앙마이           → 게임2 확대 사진 퀴즈
→ 추억극장③ 2026 한라산, 찜질방     → 게임3 7초 맞추기
→ 마블 룰렛 시상식(8회) → 엔딩
```

- 진행자 조작: ←/→ 화면 이동, S 코인 현황판 토글, 스페이스(7초 게임 타이머).
- 각 사진 폴더가 비어 있으면 해당 추억극장 챕터는 자동으로 건너뛴다.

## 게임 상세

### 1. 아빠 인생 퀴즈 (8~10문제, 배점 1)
- 화면: 사진(선택) + 질문 + 보기 4개 → 정답 공개 → "할아버지 썰 타임"(사진 크게).
- 특별 규칙: 할아버지·할머니는 직접 정답을 외칠 수 없고 손주에게 귓속말 힌트만 가능.
- 정답 공개 후 코인 버튼: `🅰 정답` `🅰 아이 정답×2` `🅱 정답` `🅱 아이 정답×2` `꽝`.
- 문제는 `data/quiz.js`에 사람이 직접 작성(예시 포함 템플릿 제공).

### 2. 확대 사진 퀴즈 (5~6문제)
- 사진을 크게 확대한 상태에서 시작, 진행자가 →를 누를 때마다 5단계로 줌아웃.
- 1~2단계에서 맞히면 3, 3~4단계 2, 5단계 1 (아이 정답 ×2 동일 적용).
- 정답 공개 시 원본 전체 사진 + 정답 텍스트.
- 문제는 `data/zoom.js`에 (사진, 확대 중심점, 정답) 작성.

### 3. 7초 맞추기 (8명 개인전)
- 한 명씩: 참가자 본인이 스페이스 또는 화면 클릭으로 시작·멈춤.
- 진행 중 초시계(0.00→)가 보인다 — 보여도 7.00에 맞추기는 어렵다. 멈추면 기록 + 7초와의 차이.
- 8명 끝나면 오차 순위표 → 순위 코인 자동 지급.

### 4. 마블 룰렛 시상식
- 코인 1개 = 이름 구슬 1개 (코인 0인 사람도 구슬 1개 보장).
- matter.js 물리: 트랙(핀 → 지그재그 경사로 → 회전 막대 반복) → **결승 깔때기 + 회전 막대**, 중력 1.7 — 한 판 약 12~20초.
- 선두가 깔때기를 빠져나오면 **슬로모션(0.22배) + 카메라 1.9배 줌인 + "두근두근" 문구** — 마지막 2~5초.
- **1등 상품부터** 한 판씩, **제일 먼저 골인한 구슬의 주인이 당첨**, 당첨자는 빠지고 다음 상품. 마지막 1명은 자동 당첨.
- 1등부터 추첨해야 코인이 많을수록 큰 상품에 유리하다(작은 상품부터 "먼저 골인=당첨"이면 코인 많은 사람이
  작은 상품을 받고 빠져 1등이 코인 적은 사람에게 가는 역전 문제). 중간에 시도한 서바이벌 방식은 너무 길어서 폐기.
- 물리는 실제 시간 기준 60스텝/초(고주사율 화면에서도 같은 속도). 25초가 넘으면 선두 구슬 당첨.

### 엔딩
- 칠순 축하 메시지 + 단체사진 타임 화면.

## 기술 구조

- 정적 사이트: `index.html` + 순수 JS 모듈 + CSS. 빌드 도구 없음.
- 외부 라이브러리는 `vendor/matter.min.js` 하나만 저장소에 포함 → 오프라인 동작.
- 상태(이름, 팀, 팀명, 코인, 진행 위치)는 `localStorage`에 저장, 새로고침 복구. 설정 화면에 "전체 초기화" 버튼.
- 사진 파이프라인: `tools/build_photos.py`가 `photos/<폴더>`의 원본을 긴 변 1920px JPEG(q82)로 줄여
  `web/photos/<폴더>/`에 저장하고 목록 `web/photos/manifest.js`를 생성. 베스트컷 목록이 있으면 그것만 사용.
- 배포: GitHub Pages(공개). 원본 `photos/`는 `.gitignore`로 제외, 축소본만 커밋.
  `<meta name="robots" content="noindex">` + `robots.txt`로 검색 노출 차단.
- `file://`로 열어도 동작해야 함(ES 모듈 대신 일반 `<script>` 사용, fetch 미사용 — 데이터는 `.js` 전역 변수).

## 화면 디자인

- 빔프로젝터 16:9 전체화면, 글자 크게(최소 본문 40px급), 밝은 축제 톤(금색·자주 포인트), 칠순 "七旬" 모티프.
- 팀 색: 🅰 주황, 🅱 파랑.

## 범위 밖 (하지 않음)

- 휴대폰 투표/버저, 서버, 배경음악, 다국어.

## 테스트

- 코인 계산·룰렛 구슬 수·7초 순위/잭팟 등 순수 로직은 `tests/`에서 Node로 단위 테스트.
- 화면은 브라우저로 전 흐름 리허설(설정 → 엔딩) 후 스크린샷 확인.
